# lt-exhibit · 工程 C 展厅展示端（E5/E6/E7）

法律实训数字平台三个前端工程之一，独立仓库、独立域名、独立发版，**独立测评范围**。见 `docs/06-工程拆分与部署.md`。

> **技术路线已定：纯网页版展示，不使用三维引擎。** 展区是"头图 + 长页 + 热点 + 版式切换"的 HTML 页面，
> 不做全景拼接、不做 WebGL 漫游，首屏不加载任何 3D 资源。

## 职责范围

| 运行模式 | 视图 | 功能点 | 说明 |
|---|---|---|---|
| immersive | E5 沉浸式前台 | EF-01~06 | 展区头图 + 长页导览、热点跳转、展项浏览、滚动动效、弱网降级、分享、访问控制 |
| lite | E6 图文简版与分享 | EL-01~04 | 单列排版、首屏性能约束、模式切换、下线页、来源标记 |
| kiosk | E7 交互终端 | TM-02 | 全屏、轮播、超时回首页、触摸唤醒、本地缓存 |

三者**共用一套内容接口与一套展项数据**，通过路由与参数选择渲染模式，不做三份内容副本（需求 9.6）。

## 技术栈

Vue 3 + Vite 5 + Pinia + axios（无 Three.js / 无 WebGL）。

配色沿用 A 端既有实现，不另立一套：主色 `#409EFF`（Element 主题色）、副色 `#3A71A8`、深底 `#141824`、面板 `#1A1F2E`。
全部收敛在 `src/styles/base.css` 的 `--ex-*` 变量里，换肤只改这一处。详见 `docs/06-工程拆分与部署.md` 第 5 章。

展区三种版式由 `exh_zone.layout` 决定，对应 `src/styles/base.css` 里的 `zone-layout--grid / flow / timeline`：

| 版式 | 值 | 呈现 |
|---|---|---|
| 图墙 | `grid` | 自适应栅格卡片墙，适合展项多、图片质量高的展区 |
| 长页 | `flow` | 单列长滚动，像图文专题，适合叙事型展区 |
| 时间轴 | `timeline` | 左侧竖线 + 节点，适合历史沿革/发展脉络类展区 |

## 启动

```bash
pnpm i
pnpm dev        # http://localhost:5174，/dev-openapi 代理到 8080 的 /openapi/v1
pnpm build      # 产物 dist/
```

## 版式预览

`preview/zone-web.html` 是**零依赖静态走查页**，浏览器直接打开即可，不需要装依赖或起服务。
它演示展区头图 + 热点 + 三种版式的实际观感，用于先定视觉再写组件；样式类名与 `src/styles/base.css` 保持一致。

## 接口边界（硬约束）

- **只调 `/openapi/v1/**`**：`/zones`、`/items/{id}`、`/publish-state`、`/share`、`/device/token`；
- 绝不调用 `/edu`、`/exh`、`/ops`、`/system` 内部接口——这是公网与内网的隔离线，也是测评边界；
- 已下架展项后端返回 **410**，前端渲染"内容已下线"页，不显示 404。

## 关键指标（需求第 12 章）

- 首屏只加载封面、标题、摘要与首段文字，**不预加载视频**；图片走 `loading="lazy"` + 响应式尺寸；
- 首屏资源 >5s 或连续 2 次素材失败 → 提示条 + 一键切 `/lite`，**不自动跳转**；
- kiosk 单展区素材缓存 ≤ 2GB，断网按缓存播放并显示"离线模式"角标。

## 当前状态

沉浸式、图文简版和终端轮播已接入公开展区和展项。展项下架后，详情接口返回 HTTP 410，页面显示失效提示。终端设备绑定、离线缓存、内部展厅登录、多媒体编排和热点仍待实现。

展示端默认通过同源 `/gallery-api` 请求公开内容。开发代理将此前缀映射到后端 `/gallery/v1`。部署时配置同样的代理，或构建时设置 `VITE_GALLERY_API`。本地上传封面由同源 `/profile` 提供，也可通过 `VITE_GALLERY_MEDIA` 指定素材来源。展示端路由需要回退到 `index.html`。
