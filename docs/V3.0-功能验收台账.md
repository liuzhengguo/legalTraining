# V3.0 功能验收台账

已核对 V3.0 功能点清单全部工作表、规格说明书和下表。三处包含相同的 140 个唯一需求编号。验收状态以该行完整业务规则、正常路径和异常路径的实跑结果为准。

隔离 MySQL 和 Redis 中通过了展区开放、草稿隔离、内部与公开发布、版本回退及下架 HTTP 410 的接口验证。Chromium 实测通过了沉浸式详情、切换图文模式、终端轮播及旧链接的下架失效页。相关需求的其余规则仍按行验收。
