# 03 接口清单

> 统一前缀：内部接口 `/edu`、`/exh`、`/ops`；开放接口 `/openapi/v1`（独立网关）。
> 响应包装沿用 RuoYi：`AjaxResult`（单对象）与 `TableDataInfo`（分页），HTTP 状态码默认 200，业务码在 `code` 字段。
> 开放接口例外：**必须使用真实 HTTP 状态码**（410 / 404 / 403），因为调用方是终端与外部系统，不是自家前端。

---

## 1. 通用约定

### 1.1 鉴权

| 类型 | 方式 | 用于 |
|---|---|---|
| 登录态 | `Authorization: Bearer {token}` | A / B / C 三个前端的全部内部接口 |
| 应用密钥 | `X-App-Id` + `X-Timestamp` + `X-Nonce` + `X-Sign`（HMAC-SHA256） | `/openapi/**` |
| 设备凭证 | `X-Device-Code` + `X-Device-Token` | 终端拉取内容与心跳 |

### 1.2 幂等

需要幂等的接口要求带 `X-Idempotency-Key`（客户端生成的 UUID）：

| 接口 | 幂等实现 |
|---|---|
| `POST /edu/submission/submit` | 唯一键 `(task_id, user_id)`，重复请求返回同一提交 |
| `POST /exh/item/{id}/publish` | 版本号 CAS，已发布直接返回当前版本 |
| `POST /openapi/v1/rec/push` | 以 `recId` 为幂等键 |
| `POST /exh/device/activate` | `device_code` 唯一，重复激活返回同一凭证 |

### 1.3 错误码

| code | 含义 | 场景 |
|---|---|---|
| 200 | 成功 | |
| 401 | 未登录 / 令牌失效 | |
| 403 | 无权限 | 含"推荐人=审核人"拦截 |
| 410 | 内容已下线 | 仅开放接口：展项已下架 |
| 404 | 不存在 / 未发布 | |
| 500 | 服务异常 | |
| 601 | 业务规则拦截 | 权重≠100、退回原因<20 字等 |
| 602 | 状态不允许该操作 | 非法状态迁移 |
| 603 | 前置条件未满足 | 未授权即推荐、素材转码未完成 |
| 604 | 重复提交 | 幂等键冲突且内容不一致 |

### 1.4 分页与时间

- 分页参数 `pageNum` / `pageSize`（默认 1 / 10，上限 500）。
- 时间格式 `yyyy-MM-dd HH:mm:ss`，服务端 `Asia/Shanghai`，截止判定到秒。

## 3. 开放接口（`/openapi/v1`）

调用方为终端、外部渠道、外部系统；全部要求应用密钥签名或设备凭证。

### 3.1 OP-02-01 展区列表

```
GET /openapi/v1/zones?level=public|internal&pageNum=1&pageSize=20
200 {
  "code": 200,
  "data": { "total": 8, "rows": [
    { "zoneId": 1, "zoneCode": "Z01", "zoneName": "序厅", "cover": "https://...",
      "intro": "...", "routeNo": 1, "openLevel": 2, "itemCount": 12 }
  ]}
}
```
约束：仅返回 `status=1 开放` 且 `open_level >= 请求级别` 的展区。

### 3.2 OP-02-02 展项详情

```
GET /openapi/v1/items/{itemId}?channel=qrcode
200 {
  "itemId": 101, "zoneId": 1, "title": "...", "summary": "...",
  "type": 3, "cover": "...", "content": { "blocks": [...] },
  "media": [ {"type":"video","url":"...","cover":"...","duration":180} ],
  "prevItemId": 100, "nextItemId": 102,
  "relatedLinks": [...], "version": 7, "publishTime": "2026-11-01 10:00:00"
}
410 { "code": 410, "msg": "内容已下线", "data": { "reasonType": "已下架", "zoneId": 1 } }
404  未发布 / 不存在
403  无权限（不泄露是否存在）
```
缓存：`Cache-Control: public, max-age=300`，发布时主动刷 CDN。

### 3.3 OP-02-03 发布状态查询

```
GET /openapi/v1/publish-state?since=2026-11-01 00:00:00
200 { "contentVersion": "20261112-01", "updateTime": "...",
      "zones": ["1","2"], "changedItems": [101, 102], "removedItems": [99] }
```
供终端做增量更新比对；`contentVersion` 由发布动作自增。

### 3.10 实现约定（已落地）

1. **签名范围**：`X-Sign = HMAC-SHA256(MD5(secret), appCode\ntimestamp\nnonce\nuri)`，其中 `uri` **只取路径、不含查询串**（与 `HttpServletRequest.getRequestURI()` 一致）。调用方带 query 时不要把它算进签名串。
2. **缓存**：`/openapi/v1/zones`、`/items/{id}` 返回 `Cache-Control: public, max-age=300`；`404 / 410` 一律 `no-store`，避免终端缓存失效内容。
3. **错误码**：`401` 签名/时间戳/nonce 不合法或重放；`403` 未授权该接口、超出配额、设备已激活/已吊销；`404` 不存在或未发布；`410` 已下线（`data.reasonType` 取自下线原因，`data.zoneId` 便于回退到展区页）；`409` 幂等冲突（`604` 已推送过、`605` 未授权或已撤回、`606` 已回写过）。
4. **降级参数**：`biz.openapi.caseUrl` 为空时 `/cases` 返回空数组 + `degrade:true`；`biz.ai.consultUrl` 为空时 `/ai/consult` 返回 `consultUrl:null` + `degrade:true`。两者都可在「参数设置」中直接维护，无需重启。
5. **隐私**：`/ai/consult` 只透出 `topic / itemId / identity / traceId`，不携带姓名、学号、手机号。
6. **留痕**：网关对成功与失败调用都写 `ops_call_log`；`/rec/push` 额外以 `req_id=recId` 记一条幂等痕迹。
