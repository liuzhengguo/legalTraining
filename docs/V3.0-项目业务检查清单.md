# 法律实训数字平台 V3.0 项目业务检查清单

检查范围包括管理端、教师工作室、学生端、门户、数字展厅、图文简版、大屏终端、对外接口，以及案例库和法律助手。审查对象为本地工作区当前代码，含未提交改动。

需求基线为 [功能点清单（131 项功能、9 项对外接口）](../docx/法律实训数字平台_V3.0_功能点清单.xlsx) 和 [分工程功能需求规格说明书](../docx/法律实训数字平台系统_分工程功能需求规格说明书_V3.0.docx)。以下问题编号用于定位，优先级按当前验收影响评估。P0 表示权限或主流程阻断，P1 表示功能缺口或规则偏差，P2 表示部署、联调或验收待完成。
