# lt-student-h5 · 工程 B 学生移动端（E3）

法律实训数字平台三个前端工程之一，独立仓库、独立域名、独立发版。见 `docs/06-工程拆分与部署.md`。

## 职责范围

| 视图 | 功能点 | 模块 |
|---|---|---|
| E3 学生学习 | ST-01-01~04 | 课程列表、任务列表与状态、任务详情、资料下载 |
| | ST-02-01~05 | 文字+附件提交、草稿、撤回、组队、逾期补交申请 |
| | ST-03-01~03 | 成绩与明细、退回重交、异议申请 |
| | ST-04-01~03 | 展项跳转、展示授权确认、我的成果 |

## 技术栈

Vue 3 + Vite 5 + Vant 4 + Pinia + axios。**不使用 Element UI**（表格与表单以移动端单列呈现为主）。

## 启动

```bash
pnpm i          # 或 npm i
pnpm dev        # http://localhost:5173，/dev-api 代理到 8080
pnpm build      # 产物 dist/，部署到 CDN
```

## 后端契约

- 只调 `/edu/**` 的学生子集（`edu:submission:*`、`edu:score:my`、`edu:rec:my`），不调 `/system/**`、`/exh/**`；
- 鉴权：学号/统一身份认证 → JWT，存 `localStorage.lt_token`；
- 跨域：D 的 CORS 白名单固定 `m.xxx.edu.cn` 与本地 `localhost:5173`，**禁 Cookie**。

## 当前状态

部署时使用 `VITE_GALLERY_BASE` 配置展厅展示端地址，课程的延伸学习入口会链接到该地址。若两个前端由同一域名分路径提供，生产环境可留空。

已接入学号登录、课程与任务、课程文件预览和下载、个人作业草稿与提交、撤回与重交、补交申请、教师评语和已发布成绩。组队、成绩异议和成果展示授权仍待实现。

生产部署可通过 `VITE_API_BASE` 指定 API 前缀。未设置时请求同源 `/dev-api`，部署时需将此前缀代理到后端。前端服务器需将页面路由回退到 `index.html`。
